# Conditional capture in the original full precision sequence

No runtime source/default changes. Reuse the original two88K-corpus/12-group/NLL128/failure-retry sequence and same private library/model/context92160/raw-sampler environment, MoE5+1=1, prefill cache deferral0. Run only after the separate nine first8K OFF captures finish and GPUs are free. Existing exact archived OFF reference and SHA are explicit.

Preserve original target/draft calls, first8K tap/state read+hash order and rollback verify/tail hash then replay/state hash order. For first8K state-hash mismatch, retain the already-read host vector and dump/describe it only after its original hash detects the difference. For first8K tap mismatch, retain existing CPU span pointers and dump after all three original tap hashes. For rollback mismatch, retain the original st plus the two final state reads, hash/compare in original order, and dump only after all original reads/hashes. No normal-path additional GPU reads or hashes. Holding final replay vectors slightly changes host allocation lifetime between state reads; exact allocator/timing equivalence is not claimed.

Capture labels, raw bytes, descriptors, target logits/tail and expected/actual state hashes at the known failure points. Describer failures are recorded separately after raw data is saved. No normalization, relaxed threshold, callback, profiler or automatic default promotion. External comparison stops on the first completed group mismatch; raw captures are saved before that group is published. A successful repeat does not explain or erase earlier failures.
