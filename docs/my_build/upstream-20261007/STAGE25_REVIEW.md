## Отдельная зависимость native от prefix cache

У нового длинного native-запроса fresh и cache расходятся уже на выходном индексе180, то есть181-м токене, query6796. Это воспроизводится без DSpark и без экспериментальной интеграции. Первое текстовое отличие находится в CSS `.card`: fresh выбирает `background: rgba(...)`, cached — `background: #fefefe`. Оба запроса выдают1024 токена; stop metadata одинакова.

Та же fresh/cache развилка сохраняется во всех пяти режимах. Поэтому из20 fresh/cache пар точны15; пять новых длинных пар отличаются. При сравнении speculative с native используется одинаковое состояние кэша: fresh с fresh, cached с cached. Отличия N=3 на404/785 являются отдельными отрицательными результатами этого сравнения.

В сводке раздельно сохранены `matching_native_criterion_passed=false` и `cache_independence_criterion_passed=false`; общий `overall_server_compatibility_passed=false`. Первый критерий не пройден из-за двух длинных N=3 ответов, второй — из-за длинной fresh/cache зависимости, которая присутствует уже у native. Первая операция этой native-развилки в этапе25 не локализована.
