# Этап 6: повторяемость sampling GLM-5.3 с MTP

Проверка выполнена: в текущем сценарии исходная неповторяемость с MTP не воспроизвелась. Все 30 запросов завершились успешно; внутри каждого из трёх режимов совпали все 10 ответов, включая перезапуск сервера. Изменений производственных исходников на этом этапе нет. Работа остановлена для review перед коммитом; DSpark остаётся следующим этапом.

Дата: 8 октября 2026 года. Ветка `my_build_upstream_20261007`, HEAD `11638b68545860e96b055798e995bb14be3d0e88`.

## Сценарий и сборка

Использован исходный GGUF этапа 0: `GLM-5.3-UD-IQ3_XXS`, архитектура GLM-DSA, семь файлов, 262,34 GiB. Размеры и даты изменения всех семи файлов совпадают с baseline. Это отдельная проверка модели IQ3_XXS из upstream-плана; диагностика reasoning-budget на IQ2 хранится в своём отчёте.

Запускался сохранённый сервер `stage5/candidate-bin/llama-server` с соответствующими библиотеками. Snapshot собран до коммита этапа 5: встроенная версия `b11012-cc7bfba3b` содержит SHA базы этапа 4, а фактические исходники snapshot затем закоммичены как `11638b685`. Перед каждым запуском проверены SHA256 snapshot; пути и SHA256 всех восьми загруженных библиотек проверены через `/proc/PID/maps`. Исходники этапа 5 совпадают с сохранёнными hashes. Подготовленное отдельно исправление Continue в snapshot не входит, его четыре исходника во время проверки не менялись. Установленный пользовательский сервер не обновлён.

Запросы полностью совпадают с JSON этапа 0: raw `/completion`, 96 фактов, 1656 prompt tokens, 128 выходных токенов, seed 1234, `cache_prompt=false`, `return_tokens=true`. Sampling: temperature 0.8, top-k 40, top-p 0.95, min-p 0.05; greedy: temperature 0. Каждый ответ содержит все 128 token IDs; кешированные prompt tokens равны нулю. Chat template и `reasoning_effort=low/max` в этом сценарии не используются.

Сервер: context 8192, batch 2048, ubatch 512, один slot, target/draft KV F16, 12 CPU threads, layer split, `fit=on`, запас 3072 MiB. MTP: встроенный NextN, draft максимум 3. Порядок GPU закреплён UUID, как в этапах 4–5: пять RTX 4090/4090 D по 49140 MiB и RTX 3090 24576 MiB, драйвер 580.159.04.

## Результат

Выполнены четыре последовательных запуска. В каждом из двух процессов с MTP отправлены пять sampling и пять greedy запросов; в каждом из двух процессов без MTP — пять sampling запросов. Сравнение выполнялось между одинаковыми запросами внутри одного режима.

| Режим | Запросов до + после перезапуска | Уникальных последовательностей token IDs | Уникальных текстов | Draft / accepted на запрос |
| --- | ---: | ---: | ---: | ---: |
| Sampling с MTP | 5 + 5 | 1 | 1 | 95 / 68 |
| Greedy с MTP | 5 + 5 | 1 | 1 | 100 / 76 |
| Sampling без MTP | 5 + 5 | 1 | 1 | 0 / 0 |

Проверены все 135 пар: по 45 пар для каждого режима, включая 25 сравнений между запусками. Первый отличающийся token ID отсутствует во всех парах. Счётчики draft/accepted повторяются без изменений. Принятие MTP: 71,58% для sampling, 76,00% для greedy.

Внутри каждого режима размещение слоёв одинаково при обоих запусках. Размещение off/on отличается из-за автоматического fit; равенство ответов между разными режимами не является критерием этой проверки. Все четыре процесса завершились с кодом 0, после проверки серверов нет, на каждом GPU осталось исходное использование 15 MiB.

## Связь с исходным расхождением

В сохранённых парах этапов 0–3 sampling с MTP расходился с индекса 37, то есть с 38-го выходного токена. В двух повторах контрольной сборки перед CUDA-патчами этапа 4 после замены GPU расхождения уже не было; в двух повторах после этих патчей его тоже нет. Исторические пары сведены отдельно.

Текущая серия подтверждает повторяемость на нынешнем оборудовании для данного prompt и seed. Она не устанавливает причину старого расхождения и не доказывает, что его устранил определённый перенос: оборудование и автоматическое размещение изменились. Причина исходной неповторяемости остаётся неустановленной. Другие prompt, seed, длинный контекст, несколько слотов и качество ответов этой проверкой не охвачены.
